# SKU 利润率分层 SOP

版本：v1.2-final
适用范围：Amazon 全 SKU 利润分层、预警诊断、调价、广告、补货、清库存与淘汰判断。

> 数据口径锁定：本店现有「实际利润」字段**已扣除退货 / 退款 / 退货相关费用**，
> 因此本 SOP 默认运行在 **模式 A（`actual_profit_scope = full_net`）**。
> 若未来更换数据源、实际利润字段不含退货，切换到 **模式 B**（见 §6.4）。

## 0. 核心原则

本 SOP 将利润率拆成三层，避免把理论毛利、实际净利和退货风险混成一个指标。

| 指标 | 是否含退货 / disposal | 代表含义 | 主要用途 |
|---|---|---|---|
| 计算利润率 `calculated_margin` | 不含 | 零退货、最好情况的理论上限 | 理论底线、虚高诊断 |
| 基础实际利润率 `actual_margin_raw` | 含（模式 A） | 已入账的真实经营结果 | 主分层基础 |
| 风险调整毛利率 `risk_adjusted_margin` | 含预估退货损失 | 理论毛利扣除退货风险后的前瞻值 | 调价、新品定价、高退货风险预警 |

最终判断逻辑：

```text
实际净利率决定分层；
计算利润率判断理论底线；
计算利润率 - 实际利润率 判断理论到实际的漏损异常；
风险调整毛利率用于调价和退货风险预警。
```

## 1. 核心口径

### 1.1 计算利润率 calculated_margin

```text
计算利润率 = (售价 - base_cost) / 售价
```

含义：理论毛利率 / 最好情况利润上限（零退货假设）。

不包含：退货率、退货处理费、disposal fee、未来可能发生的退货损失、广告费、仓储费等实际经营漏损。

用途：理论毛利校验、理论亏损判断、虚高 / 利润黑洞诊断、新品或历史不足 SKU 的兜底参考。

注意：计算利润率不是实际净利率，不能直接和目标净利率共用同一条判断线。

> 说明：本店 `base_cost` 已含产品成本、到仓成本、FBA fee、referral fee，
> 因此 `calculated_margin` 严格说是「扣履约 + 佣金后的理论贡献毛利」，
> 仍不含退货 / 广告 / 仓储等经营漏损，作为理论上限使用不受影响。

### 1.2 基础实际利润率 actual_margin_raw

```text
基础实际利润率 = 实际利润 / 净销售额
净销售额 = 销售额 - 退款
```

前提（模式 A）：实际利润字段已扣除广告费、仓租、平台费、FBA fee、退款、赔付、已入账退货费用，**不要重复扣**。

字段口径标记：

```text
actual_profit_scope = full_net          # 模式 A：已扣退货（本店当前口径）
actual_profit_scope = pre_return_adjustment  # 模式 B：未扣退货（预留，见 §6.4）
```

### 1.3 风险调整毛利率 risk_adjusted_margin

在理论毛利基础上扣除预估退货风险，用于调价、新品定价和高退货风险预警。

```text
风险调整毛利率 = (售价 - base_cost - 历史退货率 × 单次退货损失) / 售价
```

不替代计算利润率，也不替代实际利润率。三者关系：

```text
计算利润率     = 理论上限
风险调整毛利率 = 理论上限 - 退货风险
实际利润率     = 已入账真实经营结果
```

## 2. 参数配置

所有阈值必须可配置，支持全店默认、产品线覆盖、特殊 SKU 覆盖。

| 参数 | 含义 | 默认建议 |
|---|---|---:|
| `target_net_margin` | 目标净利率 | 按业务设定 |
| `calculated_margin_floor` | 计算利润率底线 | 0 |
| `risk_adjusted_margin_floor` | 风险调整毛利率底线 | 按业务设定 |
| `normal_leakage_ceiling` | 理论毛利到实际净利的正常漏损上限 | 25 个百分点 |
| `min_net_sales` | 最小净销售额阈值 | 起步：该 SKU 均价 × 3（或按业务设定绝对下限） |
| `high_margin_buffer` | 高利润缓冲线 | 5 个百分点 |
| `min_orders` | 最低订单量 | 20 |
| `profit_drop_threshold` | 利润额下滑阈值 | 20% |
| `unsellable_rate` | 退货不可再售率 | 第一版 100% |

> `normal_leakage_ceiling` 上线后建议用全目录 `理论漏损差值` 的分布（取 p75/p90）校准，
> 25pp 仅为起步默认值。

## 3. 主窗口选择

按订单量和净销售额自适应选择主窗口。

```text
如果关键字段缺失：
    主窗口 = 数据不足

否则如果 90天订单量 >= min_orders 且 90天净销售额 > min_net_sales：
    主窗口 = 90天

否则如果 180天订单量 >= min_orders 且 180天净销售额 > min_net_sales：
    主窗口 = 180天

否则如果 365天订单量 >= min_orders 且 365天净销售额 > min_net_sales：
    主窗口 = 365天

否则：
    主窗口 = 低样本
```

季节品 / 高客单低频品可用手工字段 `is_seasonal = true`，命中后优先参考 365 天或去年同期窗口。

## 4. 利润标签 profit_label

`profit_label` 为单选标签，必须按优先级判断，避免互相冲突。

优先级：

```text
数据不足 > 低样本 > 亏损 > 高利润 > 达标 > 低利润
```

### 4.1 数据不足

命中任一条件则 `profit_label = 数据不足`：

```text
缺售价 / 缺 base_cost / 缺实际利润 / 缺净销售额
主窗口净销售额 <= min_net_sales
利润率无法计算
```

### 4.2 低样本

```text
365天订单量 < min_orders  →  profit_label = 低样本
```

### 4.3 亏损

```text
主窗口实际利润率 <= 0  →  profit_label = 亏损
```

### 4.4 高利润

```text
主窗口实际利润率 >= target_net_margin + high_margin_buffer
且 30天日均利润额 >= 90天日均利润额 × (1 - profit_drop_threshold)
→  profit_label = 高利润
```

### 4.5 达标

```text
主窗口实际利润率 >= target_net_margin  →  profit_label = 达标
```

### 4.6 低利润

```text
0 < 主窗口实际利润率 < target_net_margin  →  profit_label = 低利润
```

## 5. 30 天预警 warning_label

30 天只做趋势预警，不直接定级。原因：退货、退款、赔付、仓储费可能滞后入账，30 天实际利润率容易偏高或波动过大。

### 5.1 基础指标

```text
30天日均利润额 = 30天实际利润 / 30
90天日均利润额 = 90天实际利润 / 90
```

### 5.2 30 天修正利润率

```text
30天修正利润   = 30天实际利润 - 未实现退货尾巴
30天修正利润率 = 30天修正利润 / 30天净销售额
```

如果 30 天净销售额 <= `min_net_sales`，不计算 30 天修正利润率。

### 5.3 预警触发

满足任意一个条件则 `warning_label = 利润恶化`，否则为空：

```text
30天修正利润率 < 主窗口实际利润率 - 5个百分点
30天日均利润额 < 90天日均利润额 × (1 - profit_drop_threshold)
```

## 6. 退货风险与滞后修正

### 6.1 精确口径（模式 A）

30 天实际利润里已经包含已发生的退货 / 退款，所以修正时**只补未实现退货尾巴**，不要把已入账退货再次扣除。

```text
30天修正利润 = 30天实际利润 - 未实现退货尾巴
```

### 6.2 保守口径（未实现退货尾巴拿不到时）

```text
30天修正利润 = 30天实际利润 - 预估退货损失
return_adjustment_method = conservative_full_accrual

预估退货损失 = 30天订单量 × 历史退货率 × 单次退货损失
历史退货率   = 优先取90天退货率，不足则取180天退货率
单次退货损失 = base_cost + return_processing_fee + disposal_fee
unsellable_rate = 100%   # 第一版默认，后续可按产品线配置
```

> 保守口径下退货损失偏高（含 referral、按整件报废），会让 30 天修正利润率偏保守。
> 因仅用于预警方向，宁保守勿虚高，可接受。

### 6.3 风险调整毛利率计算

```text
风险调整毛利率 = (售价 - base_cost - 历史退货率 × 单次退货损失) / 售价
```

用途：调价底线参考、新品定价参考、高退货 SKU 预警、理论利润尚可但退货正在吞利润的 SKU 识别。

### 6.4 模式 B（预留：实际利润字段不含退货）

若未来数据源变更，`actual_profit_scope = pre_return_adjustment`，则退货一分未入账，
需对**所有窗口**计提，而非只补尾巴：

```text
窗口修正利润   = 窗口实际利润 - 该窗口预估退货损失
窗口修正利润率 = 窗口修正利润 / 窗口净销售额
profit_label 用「修正利润率」定级；
30天预警的退货计提 = 全额（无已入账退货可补）。
```

## 7. 诊断标签 diagnosis_tags

`diagnosis_tags` 为可多选标签，不影响主利润标签。

### 7.1 虚高 / 利润黑洞

```text
计算利润率 - 主窗口实际利润率 >= normal_leakage_ceiling
且 主窗口实际利润率 < target_net_margin
→  打标：虚高·利润黑洞
```

含义：理论毛利到实际净利之间的漏损异常大，优先检查广告、退货、仓储、促销、赔付、FBA fee 等。

### 7.2 理论亏损

```text
计算利润率 <= calculated_margin_floor  →  打标：理论亏损
```

注意：不要用 `计算利润率 < target_net_margin` 判断理论亏损，因为计算利润率是毛利口径，`target_net_margin` 是净利口径。

### 7.3 退货风险高

```text
风险调整毛利率 <= risk_adjusted_margin_floor  →  打标：退货风险高
```

含义：纯理论毛利不一定差，但按历史退货率扣除退货损失后，毛利安全边际不足。

### 7.4 数据异常

命中任一条件则打标 `数据异常`：

```text
净销售额 <= min_net_sales / 利润率无法计算 / 关键字段异常
```

### 7.5 退货滞后修正

```text
return_adjustment_method = conservative_full_accrual  →  打标：退货滞后修正
```

## 8. 差值指标

```text
利润率差值     = 主窗口实际利润率 - target_net_margin       # 正=超标, 负=欠标
理论漏损差值   = 计算利润率 - 主窗口实际利润率              # 判断虚高 / 利润黑洞
退货风险差值   = 计算利润率 - 风险调整毛利率                # 退货吞掉了多少理论毛利
```

## 9. 决策动作

| 标签 / 状态 | 建议动作 |
|---|---|
| 高利润 | 保库存、稳广告、可加投测试 |
| 达标 | 正常运营，关注 30 天趋势 |
| 低利润 | 查价格、广告、促销、退货、FBA fee、仓储费 |
| 亏损 | 控广告、提价、降成本、清库存评估 |
| 利润恶化 | 进入预警队列，优先查广告、退货、价格、促销、Buy Box、库存 |
| 虚高·利润黑洞 | 重点查广告费、仓储费、促销折扣、退货、赔付、FBA fee 异常 |
| 理论亏损 | 理论上卖一单就不合理，优先提价、降本、停补、清库存评估 |
| 退货风险高 | 查退货原因、包装、适配性、Listing 预期管理、是否需要提价 |
| 低样本 | 不按实际利润定级，结合计算利润率、风险调整毛利率、战略价值、库存判断 |
| 数据不足 | 补齐售价、base_cost、实际利润、净销售额等关键字段 |

## 11. 最终定稿

```text
计算利润率保留为零退货理论上限；
实际利润率用于经营分层（本店口径：已扣退货，模式 A）；
风险调整毛利率用于调价和退货风险判断；
窗口按订单量和净销售额自适应；
30天只做预警，并只修正未实现退货尾巴。
```
